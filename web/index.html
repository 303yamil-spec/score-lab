DATA SOURCES & MODEL

Settings

Configure historical statistics

SportyBet MCP provides fixtures, markets and odds, but not team history or final results. For those, create a football-data.org token and add it to the project’s local .env file as FOOTBALL_DATA_API_KEY=your_token, then restart the server. The key stays on the backend and is never sent to this page.

Without that token, any estimate is explicitly marked as low-confidence and market-implied from actual 1X2 prices. Unsupported or unavailable data is not fabricated.

Responsible use

Probabilities are model estimates, not guaranteed results or financial advice. This app does not place bets, access betting wallets, or create booking codes.
